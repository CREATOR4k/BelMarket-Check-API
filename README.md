# BelMarket-Check-API

API / скрипт на Python для проверки чеков (Беларусь) и сохранения результатов в JSON.

## Структура проекта

- `main.py` — основной исполняемый файл / логика работы с API.
- `Check/` — директория с модулями или данными для проверки чеков.
- `result.json` — пример или результат обработки данных.

## Установка и запуск

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com
   cd BelMarket-Check-API
   ```

2. Установите зависимости (если используются):
   ```bash
   pip install -r requirements.txt
   ```

3. Запустите проект:
   ```bash
   python main.py
   ```
